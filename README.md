# AlphaLens Enterprise v15.1

全球股票行情、公司資料、財務趨勢、AI 研究、新聞與個人持股的響應式投資平台，支援台股、A 股與美股。

## 啟動

- Windows：雙擊 `start.cmd`
- macOS / Linux：`npm start`
- 開啟 `http://127.0.0.1:3000`

本機伺服器核心不需要下載第三方 npm 套件。建議使用 Node.js 20～24。

## v15.1 主要模組

- 多來源行情引擎與 SSE 即時更新
- 台股、A 股中文名稱引擎
- 多來源公司資料引擎
- 最近 8 季財務趨勢與來源覆蓋率
- AI 證據模式：數值、來源、日期、缺值與評級改變條件
- OpenAI／Gemini／本機規則三層 AI 備援
- 智慧提醒與瀏覽器系統通知
- 投資決策儀表板
- 個人持股、比例圖、警示燈與景氣訊號
- 新聞與官方公告整合
- PWA 與行動版底部導航

## 穩定性設計

- 首先顯示本機快取，再於背景同步完整資料。
- 快速切換股票時取消舊請求，避免舊資料覆蓋新畫面。
- SSE 使用心跳、瀏覽器原生重連與 watchdog。
- 後台重連採指數退避；斷網恢復後自動重新同步。
- 儀表板、新聞與持股更新不允許同時重複執行。
- 外部 API 全部設有逾時、備援、快取與明確降級標示。

## 智慧通知

在首頁儀表板按「開啟系統通知」。通知功能需在 HTTPS 網站或 localhost 使用；若瀏覽器不支援，頁內警示仍會保留。

## AI 設定

複製 `.env.example` 為 `.env`，設定 OpenAI 或 Gemini 金鑰。沒有金鑰時會使用本機規則引擎。AI 供應商只補充研究敘述；證據欄位仍由平台的實際資料生成。

## 驗證

```bash
npm run verify
```

會執行語法、單元、靜態整合、HTTP、SSE、壓力、多輪重複與 Chromium 桌面／手機端到端測試。

## 注意

免費行情與公開網站可能延遲、限流或調整格式。平台會自動備援並標示資料狀態。AI 分析是研究輔助，不構成投資建議。
