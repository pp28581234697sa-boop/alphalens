# AlphaLens Pro v6

功能：多市場搜尋、多資料源備援、即時輪詢、自選同步、TradingView K 線、新聞摘要、AI 基本面分析、本地快取與股票目錄同步。

## 啟動
雙擊 `start.cmd`，或執行 `npm.cmd install` 後 `npm.cmd start`。

## 重要限制
免費 API 不保證所有市場即時或完整。台股、A 股資料依供應商方案與代號支援而異。畫面會顯示來源；若顯示警告即非正式即時價。


## v6.1 搜尋修正
- 搜尋框右側新增明確「搜尋」按鈕。
- 點擊按鈕與 Enter 鍵共用同一搜尋流程。
- 搜尋期間顯示「搜尋中」並防止重複送出。
- 空白搜尋會提示輸入代號或公司名稱。


## v6.2 台股與 A 股行情修正
- 正式 API 無法提供免費盤中行情時，改用 Yahoo Finance 公開圖表端點作近即時備援。
- 台股自動嘗試 `.TW`／`.TWO`；A 股自動轉換 `.SS`／`.SZ`／`.BJ`。
- 介面會標示「Yahoo Finance 備援・可能延遲」，不把它標成交易所即時行情。
- 免費方案或來源失效時才顯示展示價格。


## v6.3 即時更新整合

- 台股優先：Fugle → Twelve Data → FMP → FinMind 日行情 → Yahoo 備援
- A 股優先：AllTick → Twelve Data → FMP → Yahoo 備援
- 美股優先：Finnhub → Twelve Data → FMP
- 新增「立即更新」按鈕；按下會清除該股票快取並重新取價
- 顯示資料來源、更新時間、即時／延遲警告
- WebSocket 每 15 秒自動更新目前有人觀看的股票
- FinMind 的 TaiwanStockPrice 是日行情備援，不會標示成盤中即時價


## v6.4 免登入模式

- 已移除前端登入與註冊介面
- AI 分析可直接使用，不再要求登入
- 自選股與收藏改存瀏覽器 localStorage
- 收藏資料只保存在目前這台電腦與瀏覽器
- 清除瀏覽器網站資料後，收藏清單也會被清除


## v6.5 K 線容錯

- 台股與 A 股預設使用內建 K 線，不再依賴 TradingView 是否收錄該商品
- 可切換「內建 K 線」與「TradingView」
- TradingView 顯示商品不存在時，切回內建 K 線即可
- 內建 K 線使用 `/api/history`，來源可為 FMP、Twelve Data 或 Yahoo 備援
- K 線區間支援 1D、5D、1M、6M、1Y、5Y


## v6.6 公司介紹卡
- 新增「這家公司在做什麼？」資訊卡
- 顯示公司簡介、產業、交易所、地區、網站、CEO、員工人數
- 優先使用 FMP，美股由 Finnhub 備援
- 資料不足時顯示本地產業說明


## v6.7 公司資料網路備援

公司介紹來源順序：
1. Financial Modeling Prep
2. Finnhub（美股）
3. Wikipedia 中文／英文 API
4. 本地股票目錄

每張公司介紹卡會顯示資料來源；可點擊來源查看原始頁面。系統不會把無來源內容當作已驗證事實。


## v6.8 介面調整

- 移除圖表旁的「內建 K 線／TradingView」切換框

## v7.1 完整穩定性修正

## v7.3 啟動修正

- 修正健康檢查 `$r.StatusCode-eq200` 缺少空格，導致瀏覽器不會自動開啟的 BUG。
- 後端改在最小化視窗執行，啟動器不再停在伺服器輸出畫面。
- 健康檢查通過後才開啟 `http://127.0.0.1:3000`。
- 啟動失敗時直接顯示 `server.log`。
- 新增 `open-site.cmd` 與 `diagnose.cmd`。


## v7.4 排行榜與穩定性升級

- 新增漲幅、跌幅、成交量、成交值、熱門排行五種模式

- 上漲紅色、下跌綠色、平盤灰色

- 後端暫時斷線時顯示離線快取，不再整塊空白
- 後端恢復後自動重新載入
- 排行範圍目前為各市場 15 檔代表性股票；完整全市場排行仍需批次市場快照授權
